# FROST MC — Website 💜🖤

موقع كامل (HTML + CSS + JS) بدون أي تثبيت أو Build.

## الملفات
```
index.html          الصفحة الأساسية
css/style.css       التصميم والأنيميشن
js/config.js        إعدادات السيرفر (IP، Discord، الموسيقى...)
js/data.js          المحتوى الافتراضي (الإدارة، الأخبار، المتجر...)
js/i18n.js          الترجمة عربي/إنجليزي
js/effects.js       الثلج + الكتابة التلقائية + التأثيرات
js/music.js         موسيقى YouTube (تشغيل/إيقاف + صوت)
js/app.js           الصفحات والراوتر وحالة السيرفر
js/admin.js         لوحة الإدارة
js/boot.js          شاشة الدخول وبدء الموسيقى
assets/             اللوجو والبانرات
data/content.json   (اختياري) المحتوى المنشور من لوحة الإدارة
```

## التشغيل محلياً
افتح فولدر المشروع في الترمنال:
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`. (فتح index.html مباشرة بيشتغل، لكن ملف data/content.json محتاج سيرفر.)

## ضبط السيرفر
1. افتح `js/config.js` (أو لوحة الإدارة ← إعدادات السيرفر).
2. حط `ip` و `port` من لوحة Wispbyte، وبعدها حالة السيرفر وعدد اللاعبين بتظهر تلقائياً (عن طريق api.mcsrvstat.us).
3. لو الـ IP لسه مش جاهز، الموقع بيعرض «الـ IP لسه مش مضاف» وزر PLAY NOW بيوجّه للديسكورد.

## الموسيقى
بتشتغل أول ما الزائر يضغط «ادخل عالم FROST» (المتصفحات بتمنع الصوت التلقائي قبل أي ضغطة، فده أقرب حل ممكن). زر الصوت وشريط الـ Volume فوق. لتغيير الأغنية: `musicVideoId` في config.js.

## النشر المجاني (اختر واحد)
- **Cloudflare Pages** (الأفضل): ارفع الفولدر مباشرة (Direct Upload) أو اربطه بـ GitHub. سريع ومجاني.
- **GitHub Pages**: ارفع الملفات في Repo ← Settings ← Pages ← Branch main.
- **Netlify**: اسحب الفولدر في netlify.com/drop.

## تحديث المحتوى لكل الزوار
1. افتح `#/admin` وعدّل (لاعبين، مبدعين، أخبار، متجر، تصويتات...).
2. اضغط **البيانات ← تصدير content.json**.
3. حط الملف في فولدر `data/` وارفع الموقع تاني.

## ⚠️ حدود صريحة (مهم تعرفها)
هذا موقع **Static** (بدون سيرفر)، وده معناه:
- **لوحة الإدارة** بتحفظ التعديلات في متصفحك كمسودة، ومفيش تسجيل دخول حقيقي. أي حد يفتحها هيعدّل في متصفحه هو بس ولا يأثر على الزوار.
- **Discord OAuth وصلاحيات حقيقية، تصويت يمنع التكرار على مستوى الحساب، وقاعدة بيانات مشتركة** كلهم محتاجين Backend. الحل المجاني المناسب: **Supabase** (قاعدة بيانات + Discord Login) أو **Cloudflare Workers + D1**. الـ Client Secret بتاع Discord لازم يتحط في الـ Backend فقط، مش في أي ملف هنا. تقدر تطلب مني أبني الخطوة دي.
- **التصويت** حالياً مرة واحدة لكل متصفح (localStorage) والنتائج المعروضة من البيانات المنشورة + صوتك.
- **Kick Live/Offline التلقائي**: Kick بيمنع القراءة المباشرة من المتصفح. حط في `kickProxy` رابط Cloudflare Worker بسيط، أو استخدم زر Live اليدوي من لوحة الإدارة.
- صور سكن اللاعبين 3D من mc-heads.net، وحالة السيرفر من api.mcsrvstat.us (محتاجين إنترنت).
- اللاعبين والمبدعين فاضيين عمداً (مفيش بيانات وهمية): ضيفهم من لوحة الإدارة. الإدارة (Santa وزيدان وناروتو) مضافين بالـ Discord IDs اللي بعتهم.
- أسعار المتجر = 0 (تظهر «تواصل معنا»)، وقوانين السيرفر الافتراضية عامة، عدّلها.
